# 四家银行真实数据核账与历史重建

核账日期：2026-10-04。计算样本日期：2025-05-16。

## 结论

四家银行均已通过实际数据输入运行核心计算与发布流程；每家用 252 对同区间银行/指数收益计算场景 beta、LRMES 和 SRISK。JSON/CSV 数值一致；另用独立的中心化乘积公式重算 beta 与资本缺口，输出差异在四舍五入误差以内。

这证明数据输入、公式和发布链能在真实样本上联通，并不证明模型有预测能力，也不是最新银行风险排名。

## 本轮发现并修复

1. **历史比较期倒灌**：晚发表的旧年度比较数字可能覆盖更新季度。现在先选择最新报表期，再选择截至当时已公布的该期版本。
2. **重述不应提前可用**：更正资料只在其公布后启用，不能回写成原来就知道。SMFG 的 2025-06-20 公告更正现金流项目，本次选取的负债和股本行不在该公告列出的更正范围；仍保留原文件与更正文件指纹。
3. **会计准则混用**：SMFG 的 J-GAAP 和 IFRS 数字并不相同。输入流必须明确准则，混用会拒绝处理。
4. **旧报表反复转载延长保鲜期**：陈旧程度改从报表期末计算，而不是从最近一次重复引用的发布日期计算。
5. **行情币种元数据冲突**：Wind 返回的 BARC.L 数据单位标成美元，但伦交所 BARC 普通股以 GBX 报价，发行人回购公告也使用便士。示例作有来源的显式覆盖，告警保留；默认情况下不允许静默覆盖冲突。
6. **复权价格用于市值**：Wind 默认前复权值不能直接当未复权市值价格。行情使用 2025-05-16 为复权基准；另以 2024-12-31 为基准请求 JPM，得到 239.710，与年报 239.71 对上。收益序列与估值日价格用途分开。
7. **服务存活不等于数据健康**：新增缺失覆盖、覆盖下降、过期快照、旧财报、币种/准则变化和异常输入跳变告警；/health 分别提供 service_status 和 data_status。

## 明确边界

- Fed H.10 的 2025-05-16 观测值在 2025-05-19 发布，因此本结果标记 historical_reconstruction；它不是 5 月 16 日当时可执行的无前视回测。
- 供应商行情是现在取得的历史序列，不是带发布时间的完整历史数据快照。
- 市值采用最近披露股数，并非已验证的每天精确股数。回购、增发、拆股需要进一步连续跟踪。
- 并未统一不同国家会计准则，只明确区分并阻止误混。
- 本次研究没有验证风险模型对真实危机的预测能力。
- 原始 Wind 历史行情保留在私有工作目录，没有打包进公开源码。生产部署仍需要用户有权使用的行情接口或 CSV 文件；不能把本次连接当作服务器已经接入 Wind。
